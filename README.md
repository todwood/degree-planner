## Brand & Design Specifications
- **Background**: Soft off-white (`#F7F5F0`), light beige (`#FBF8F4`).
- **Primary**: Deep Purple (`#6C5CE7` - `#5A4FCF`).
- **Secondary**: Soft Lavender (`#8F85F3` - `#A298FE`).
- **Neutrals**: Charcoal (`#2B2B2B`), graphite (`#5A5A5A`).
- **Accent**: Neon Yellow (`#F5F000`) for high-status highlight badges.
- **Typography**: Poppins (Headlines) & Montserrat (Body).

---

## Sections Included
1. **Hero**: High-status value proposition with interactive live cluster terminal.
2. **Social Proof & Metrics**: Credibility logos and four enterprise metric ribbons.
3. **Problem → Solution**: Comparison between fragile ad-hoc prompts and the deterministic DOE framework.
4. **Platform Capabilities**: 6 luxury cards covering self-annealing recovery, air-gapped security, model router, MCP ecosystem, real-time observability, and multi-agent swarms.
5. **How It Works**: 3-step numbered architectural pipeline (Directive, Orchestration, Execution).
6. **Interactive Use Cases**: Dynamic tabbed viewer for DevOps, Data Engineering, SecOps, and Product Analytics with live code preview switching.
7. **Pricing Plans**: Interactive Monthly/Annual billing switcher with highlighted Pro/Scale plan.
8. **Call to Action**: High-conversion early-access email capture.
9. **Footer**: Real-time cluster status indicator and comprehensive site navigation.
